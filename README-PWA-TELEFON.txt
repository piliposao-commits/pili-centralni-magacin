PILI CENTRALNI MAGACIN - PWA ZA TELEFON

Ova verzija dodaje instalaciju na Android telefonu kao aplikaciju.

1. Raspakuj preko postojeceg projekta.
2. npm install
3. npm run build
4. vercel --prod

POSLE DEPLOY-A NA TELEFONU:
- Otvori Chrome, ne Google Search aplikaciju.
- Magacin: https://pili-centralnii-magacin.vercel.app
- Trebovanje: https://pili-centralnii-magacin.vercel.app/trebovanje
- Chrome meni (tri tacke) -> Dodaj na pocetni ekran / Instaliraj aplikaciju.

Ako je stara verzija vec bila otvorena, potpuno zatvori Chrome pa ponovo otvori link.
