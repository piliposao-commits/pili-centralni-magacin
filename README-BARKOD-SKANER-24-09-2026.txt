PILI CENTRALNI MAGACIN – BARKOD + SKENIRANJE TELEFONOM
24.09.2026.

Izmene u /trebovanje:
- Barkod se jasno prikazuje na svakoj kartici artikla.
- Pretraga radi po nazivu, šifri i barkodu.
- Dodato dugme 📷 SKENIRAJ.
- Skeniranje koristi zadnju kameru telefona i automatski pronalazi artikal po barkodu.
- Barkod se vidi i na ekranu kontrole trebovanja.
- Ako kamera nije dozvoljena, aplikacija traži dozvolu.

Instalacija:
1. Raspakovati preko postojećeg pili-centralni-magacin foldera.
2. Ne brisati postojeći .env.local i .vercel folder.
3. Pokrenuti: npm install
4. Pokrenuti: npm run build
5. Pokrenuti: vercel --prod
