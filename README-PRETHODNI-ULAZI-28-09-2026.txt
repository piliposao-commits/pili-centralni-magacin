PILI CENTRALNI MAGACIN — PRETHODNI ULAZI ROBE

DODATO U ADMIN -> ULAZ ROBE:

Ispod plavog dugmeta "IZABERI VIŠE SLIKA" i narandžastog
"SLIKAJ JEDNU STRANU" sada postoji sekcija:

PRETHODNI ULAZI ROBE

U sekciji se prikazuju svi ranije proknjiženi ULAZI, najnoviji prvi.

Za svaki ulaz vidi se:
- dobavljač
- broj dokumenta
- datum i vreme knjiženja
- broj stavki
- ukupna količina
- ukupna vrednost

Klikom na konkretan ulaz otvara se kompletan sadržaj:
- šifra
- naziv artikla
- barkod
- JM
- količina
- cena
- vrednost

Nije potreban novi SQL.
Podaci se čitaju direktno iz postojećih cm_documents i cm_document_lines tabela.
